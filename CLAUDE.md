# sublevel

A small first-person, physics-based game demo in the style of late-90s facility shooters, built entirely from code: no image, model or audio files, and no runtime dependencies.

## Rules

- **Zero runtime dependencies.** Browser APIs only: WebGPU, Web Audio, Pointer Lock, DOM. Never add an npm package. `@types/bun` is the only dev dependency.
- **Bun is the only tool.** No bundler config, no other CLIs.
- **Everything is generated by code.** Textures, meshes and sounds are produced procedurally at startup.
- **Original content only.** Same genre and era as the inspirations, but no names, characters, logos or specific designs from any existing game.

## Commands

- `bun install` — once per checkout (types only).
- `bun run gate` — type check, format check and tests. Must pass before any commit.
- `bun fmt` — format. Run it before the gate.
- `bun run dev` — dev server on port 3210 for `index.html`.
- `bun ./demos/<name>.html --port <port>` — serve a module demo page.
- `bun run dist` — single-file build into `dist/`.

Do not add a script named `check`, `fmt` or `test` to `package.json`: it would shadow Bun's built-in command of the same name. This Bun version has no `bun lint`.

## Layout and ownership

Each module owns one folder under `src/` and exports the factory named for it in `src/core/api.ts` from its `index.ts`.

- `src/math/`, `src/core/`, `src/main.ts`, `index.html` — shared skeleton. Do not edit from a module branch; if a contract needs to change, say so in your report instead.
- `src/textures/`, `src/render/`, `src/physics/`, `src/level/`, `src/audio/`, `src/player/`, `src/props/`, `src/hud/` — one module each.
- `demos/<module>.html` — optional standalone page for looking at or listening to a module by itself.

Modules import from `src/math` and `src/core` only, never from each other. The game wires them together in `src/main.ts`.

## Conventions

- Right-handed, Y up. Metres, seconds, kilograms, radians. Yaw 0 looks along -Z, +X is to the right.
- Matrices are column-major `Float32Array(16)`; clip-space depth is 0..1.
- Triangles wind counter-clockwise. UVs are in texture repeats, with v growing downward.
- Simulation runs at a fixed 60 Hz (`FIXED_DT`); rendering runs once per display frame.
- Anything random takes a seed and uses `createRng` from `src/core/rng.ts`, so results are reproducible.
- Keep logic pure and testable under `bun test` (no DOM, WebGPU or AudioContext in tested code). Put browser-only code in thin wrappers.
- Tests live next to the code as `*.test.ts`.
- Shaders are `.wgsl` files imported with `with { type: "text" }`.
- The built-in DOM types do not type `canvas.getContext("webgpu")`; cast the result to `GPUCanvasContext | null`.
